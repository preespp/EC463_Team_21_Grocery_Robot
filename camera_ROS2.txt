- Purpose: Maps barcode text → known location in the map frame
- Format: (x, y, yaw_deg)
- Median Depth Sampling median_depth(depth_frame, x, y, k=7)
Samples a k×k window around the barcode center
Computes median depth
Reduces noise and missing depth values
- Converts 2D yaw angle into a ROS quaternion: euler_to_quaternion(yaw_deg)
Used for PoseStamped messages because ROS requires quaternions, not Euler angles.
- Barcode Corner Extraction: to_int_pts(position)

bar_code.py
Topic | Usage
barcode_detections_json	| Raw detection info (JSON)
barcode_point | 3D barcode position in camera frame
barcode_pose | Known barcode pose in map frame
camera/color/image_raw | Debug visualization

1. /barcode_detections_json Type: std_msgs/String
A JSON string containing all barcode detections in the current frame.
Each JSON message includes: Timestamp, List of detected barcodes, Barcode text, Format, Pixel center, Distance, 
3D point (camera frame), Whether barcode is registered, Map pose (if registered)

Example:
{
  "timestamp": 1690000000.123,
  "detections": [
    {
      "text": "Location_1",
      "format": "QR_CODE",
      "center_px": [640, 360],
      "distance_m": 1.42,
      "point_camera_m": [0.12, -0.05, 1.42],
      "registered": true,
      "map_pose": {
        "x": 3.0,
        "y": 4.0,
        "theta_deg": 0.0
      }
    }
  ]
}

2. /barcode_point Type: geometry_msgs/PointStamped
A single 3D point representing the barcode position relative to the camera.
header.frame_id = "camera_link"
point = (X, Y, Z)  # meters
When it publishes: Once per detected barcode. If multiple barcodes exist → multiple messages per frame

3. /barcode_pose Type: geometry_msgs/PoseStamped
A known, fixed pose in the map frame corresponding to a registered barcode.
header.frame_id = "map"
pose.position = (x, y, 0)
pose.orientation = quaternion(yaw)
The pose comes from: BARCODE_MAP[text] → (x, y, theta)

4. /camera/color/image_raw Type: sensor_msgs/Image
A debug image with: Barcode outlines, Barcode text, Distance overlay
encoding: bgr8
frame_id: camera_link

camera_vision.py
Topic | Meaning
detections_json | All YOLO detections (JSON)
detection_point | 3D point per detection
camera/color/image_raw | Debug image

1. /detections_json Type: std_msgs/String
JSON-encoded string containing: Timestamp, List of detected objects
Example payload:
{
  "timestamp": 1690000000.123,
  "detections": [
    {
      "class_id": 0,
      "class_name": "person",
      "confidence": 0.87,
      "bbox": [120, 60, 300, 420],
      "center_px": [210, 240],
      "distance_m": 2.13,
      "point_m": [0.45, -0.12, 2.13]
    }
  ]
}

When it publishes: Only if at least one object is detected

2. /detection_point Type: geometry_msgs/PointStamped
A single 3D point per detected object: Represents object center in camera frame
header.frame_id = "camera_link"
point.x = X
point.y = Y
point.z = Z
When it publishes: Once per detected object; Multiple messages per frame if multiple objects

3. /camera/color/image_raw Type: sensor_msgs/Image
zoriginal color image with YOLO bounding boxes drawn, Labels + distance overlay
encoding: bgr8
frame_id: camera_link
